**Install:** download `FreeFlow.exe` below and double-click it. If Windows SmartScreen appears, click **More info → Run anyway** (the app isn't code-signed).

Then paste a free API key from https://console.groq.com/keys into Settings, click **Save**, and hold **Ctrl + Win** in any app to dictate.

- Windows 10 / 11, 64-bit. A single self-contained file, so there's nothing else to install.
- `FreeFlow.exe.sha256` holds the file's SHA-256 checksum.
- Built and smoke-tested automatically on GitHub's Windows runners. See [windows/README.md](https://github.com/kanishakusingai/wisprflow/blob/main/windows/README.md) for features and privacy details.
